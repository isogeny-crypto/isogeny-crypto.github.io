QFESTA

Quaternion Fast Encryption from Supersingular Torsion Attacks

Published

June 22, 2026

Modified

July 2, 2026

1 Overview

QFESTA (Quaternion Fast Encapsulation from Supersingular Torsion Attacks) is a new isogeny-based public-key encryption (PKE) and key encapsulation mechanism (KEM) based on the FESTA protocol [NaOn24].

FESTA uses the SIDH attack machinery for decryption, which natively imposes strong smoothness constraints on the degrees of the underlying isogenies (\(d_A, d_1, d_2\)), forcing them to be large and leading to significant data sizes and computational overhead. To circumvent these limitations, QFESTA introduces a novel technique leveraging quaternion algebras to compute the codomain and point images of non-smooth degree isogenies from a special starting curve. This eliminates the smoothness restriction for degrees \(d_A\) and \(d_1\), vastly shrinking parameter sizes.

2 Protocol Design

The main innovation in QFESTA’s design is the sub-algorithm RandIsogImages, which evaluates non-smooth degree isogenies using Kani’s lemma and quaternion endomorphisms. Finally, to achieve indistinguishability against chosen ciphertext attacks (IND-CCA) in the quantum random oracle model (QROM), the core One-Way Chosen Plaintext Attack (OW-CPA) secure PKE is wrapped using the Fujisaki-Okamoto (\(FO^{\not\perp}\)) transform.

2.1 The RandIsogImages Algorithm

Given a special supersingular elliptic curve \(E_0/\mathbb{F}_{p^2}\) with \(j\)-invariant 1728, its known maximal order \(\mathcal{O}_0 \cong \text{End}(E_0)\), and an target non-smooth isogeny degree \(d\):

  • A smooth integer \(D = 2^{3a}\) is chosen such that \(E_0[D] \subset E_0(\mathbb{F}_{p^2})\) and \(D - d \approx p\).
  • The algorithm computes an element \(\alpha \in \mathcal{O}_0\) with a reduced norm of \(d(D-d)\) using an extension of Cornacchia’s algorithm.
  • The quaternion element \(\alpha\) is formally decomposed into \(\hat{\rho} \circ \tau\), where \(\tau\) and \(\rho\) are isogenies of degrees \(d\) and \(D-d\), respectively.
  • By leveraging Kani’s lemma (via SIDH attack components), the algorithm extracts the codomain of \(\tau\) and the images of arbitrary torsion points under \(\tau\) entirely through (2,2)-isogeny chains.

2.2 Key Generation

  • Parameters: Uses a system parameter set containing \((p, a, b, d_{A,1}, d_1, E_0, \mathcal{O}_0, P_0, Q_0)\).
  • Secret Isogeny \(\phi_A\): A random non-smooth degree \(d_{A,1}\)-isogeny is generated from \(E_0 \to E_{A,1}\) via RandIsogImages, followed by a random \(3^b\)-isogeny to the final public curve \(E_A\).
  • Masking: Torsion points on \(E_A\) are masked using a randomly sampled matrix \(\mathbf{A} \in M_2(\mathbb{Z}/2^{3a}\mathbb{Z})\).
  • Keys: The public key pk consists of the curve \(E_A\) and the masked points \((R_A, S_A)\). The secret key sk contains the isogeny path representations and the matrix \(\mathbf{A}\).

2.3 Encryption and Decryption

  • Encryption: To encrypt a message \(m \in \{0, 1\}^{3a-2}\), the sender encodes it into a diagonal masking matrix \(\mathbf{B} = \text{diag}(s_B, s_B^{-1})\) where \(s_B = 2m+1\). The sender generates a \(d_1\)-isogeny to a curve \(E_1\) using RandIsogImages and a \(3^{2b}\)-isogeny from \(E_A\) to \(E_2\). The output ciphertext encapsulates these curves and points masked by \(\mathbf{B}\).
  • Decryption: Utilizing the secret isogeny \(\phi_A\) and Kani’s lemma, the receiver can reconstruct the commutative diagrams necessary to unmask the points and solve a discrete logarithm (via Weil or Tate pairings) to retrieve the matrix \(\mathbf{B}\), and consequently the message \(m\).

3 Security Assumptions

The core OW-CPA security of the QFESTA PKE relies on specialized variants of FESTA’s distinguishing and computational problems.

  • Pseudorandomness of RandIsogImages: The foundational assumption assumes that the codomain elliptic curve \(E_1\) and its mapped torsion points \((P_1, Q_1)\) produced by RandIsogImages are computationally indistinguishable from a tuple drawn uniformly at random from valid configurations.

  • Variant DIST Problem: The security proof extends this to the public keys themselves, assuming an adversary cannot distinguish the legitimate masked points \((R_A, S_A)\) on \(E_A\) from uniformly random torsion points.

  • Hardness of Isogeny Recovery: Finding the secret isogenies (\(\phi_A, \phi_1, \phi_2\)) given the degrees (\(d_A, d_1, d_2\)) requires \(O(2^{\lambda})\) operations classically and \(O(2^{\lambda/2})\) operations via quantum attacks (using Grover’s algorithm or meet-in-the-middle strategies), satisfying the targeted security levels.
