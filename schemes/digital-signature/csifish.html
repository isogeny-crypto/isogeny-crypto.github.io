CSI-FiSh

Commutative Supersingular Isogeny based Fiat-Shamir signatures

Created

June 1, 2026

Modified

October 1, 2026

1 Overview

CSI-FiSh applies the Fiat–Shamir transform to the identification protocol of Couveignes, found independently by Stolbunov, instantiated with the CSIDH-512 class group action [BeKlVe19]. The protocol needs uniform sampling and a canonical representation of class group elements, which were out of reach while the class group of the CSIDH-512 order was unknown. The authors computed this class group and its relation lattice, finding it cyclic, so that every element can be written as a power of one generator and sampled as an exponent modulo the class number. They then shrink signatures using several public keys, quadratic twists, and, optionally, a Merkle tree that shortens the public key.

2 Scheme Design

2.1 Public Parameters

  • \(p = 4 \cdot \ell_1 \cdots \ell_n - 1\): the CSIDH-512 prime, with \(n = 74\) small distinct odd primes \(\ell_i\).
  • \(E_0 : y^2 = x^3 + x\) over \(\mathbb{F}_p\), with \(\mathbb{F}_p\)-rational endomorphism ring \(\mathcal{O} = \mathbb{Z}[\pi]\), where \(\pi\) is the Frobenius endomorphism.
  • \(\mathrm{Cl}(\mathcal{O})\): the class group, cyclic of order \(N = \#\mathrm{Cl}(\mathcal{O}) \approx 2^{257.136}\) and generated by \(\mathfrak{g} = \mathfrak{l}_1 = \langle 3, \pi - 1 \rangle\). For \(a \in \mathbb{Z}_N\), write \([a]E = \mathfrak{g}^a \star E\).
  • Evaluating \([a]E\): rewrite \(\mathfrak{g}^a\) as \(\prod_i \mathfrak{l}_i^{e_i}\), then shorten the exponent vector \((e_1, \dots, e_n)\) by solving a closest-vector problem (in the \(\ell_1\)-norm) in the relation lattice \(L = \{ \mathbf{z} \in \mathbb{Z}^n : \prod_i \mathfrak{l}_i^{z_i} = (1) \}\). The result is evaluated like a CSIDH action.
  • \(S\), \(t\): the number of public curves plus one, and the number of parallel rounds. \(\mathcal{H}\): a hash function.

2.2 Identification Protocol

The basic protocol of Couveignes and Stolbunov. The secret key is \(a \in \mathbb{Z}_N\), and the public key is \(E_1 = [a]E_0\).

  1. Commitment: the prover samples \(b \in \mathbb{Z}_N\) uniformly and sends \(E = [b]E_0\).
  2. Challenge: the verifier sends a random bit \(c \in \{0, 1\}\).
  3. Response: the prover sends \(r = b - c \cdot a \bmod N\).
  4. Verification: the verifier accepts if \(E = [r]E_c\).

The soundness error is \(1/2\). CSI-FiSh reduces it as follows:

  • More public keys: publish \(E_i = [a_i]E_0\) for \(i = 1, \dots, S-1\). The challenge is then \(c \in [0, S)\), and the response is \(r = b - a_c \bmod N\) (with \(a_0 = 0\)). The soundness error drops to \(1/S\).
  • Quadratic twists: the twist \(E_i^t\) is \(\mathbb{F}_p\)-isomorphic to \([-a_i]E_0\). Setting \(E_{-i} = E_i^t\) extends the challenges to \(c \in \{-S+1, \dots, S-1\}\) at no extra communication cost, and the soundness error drops to \(1/(2S-1)\).
  • Hashed commitments: the prover sends one hash of all \(t\) commitments instead of the curves.
  • Merkle variant: the public key becomes the root of a Merkle tree over \(E_1, \dots, E_{S-1}\), keyed by a random \(\mathsf{MerkleKey}\). A signature opens the (at most \(t\)) curves it uses.

2.3 Key Generation

  1. For \(i = 1, \dots, S-1\): sample \(a_i \in \mathbb{Z}_N\) uniformly and compute \(E_i = [a_i]E_0\).
  2. Output \(\mathsf{sk} = (a_1, \dots, a_{S-1})\) and \(\mathsf{pk} = (E_1, \dots, E_{S-1})\).

2.4 Signing

Fiat–Shamir with \(t\) parallel rounds, for a message \(m\):

  1. For \(i = 1, \dots, t\): sample \(b_i \in \mathbb{Z}_N\) uniformly and compute \(E^{(i)} = [b_i]E_0\).
  2. Compute the challenges \((c_1, \dots, c_t) = \mathcal{H}(E^{(1)} \| \cdots \| E^{(t)} \| m)\), with \(c_i \in \{-S+1, \dots, S-1\}\).
  3. For \(i = 1, \dots, t\): \(r_i = b_i - \mathrm{sign}(c_i)\, a_{|c_i|} \bmod N\).
  4. Output \(\sigma = (r_1, \dots, r_t, c_1, \dots, c_t)\).

2.5 Verification

  1. Set \(E_{-i} = E_i^t\) for \(i = 1, \dots, S-1\).
  2. For \(i = 1, \dots, t\): compute \(E^{(i)} = [r_i]E_{c_i}\).
  3. Accept if \((c_1, \dots, c_t) = \mathcal{H}(E^{(1)} \| \cdots \| E^{(t)} \| m)\).

For security level \(\lambda\), \(t = \lambda / \log_2 S\). A signature has \(t(\lceil \log_2 N \rceil + \lceil \log_2 S \rceil)\) bits, and signing and verifying each take \(t\) group actions. \(S\) trades public-key size against signature size. For example, \(S = 2\) with \(t = 56\) gives a 128 B public key and 1880 B signatures, while \(S = 2^{15}\) with \(t = 7\) gives a 2 MB public key and 263 B signatures. These figures use a hash function \(2^k\) times slower than SHA-3, which lets \(t\) be reduced.

3 Security Assumptions

CSI-FiSh is strongly existentially unforgeable under chosen-message attacks (sEUF-CMA) in the quantum random oracle model, assuming:

  • Group Action Inverse Problem (GAIP): given a curve \(E\) with \(\mathrm{End}(E) = \mathcal{O}\), find an ideal \(\mathfrak{a} \subset \mathcal{O}\) such that \(E = \mathfrak{a} \star E_0\). Borrowed from CSIDH.
  • Multi-Target GAIP (MT-GAIP): given curves \(E_1, \dots, E_k\) with \(\mathrm{End}(E_i) = \mathcal{O}\), find an ideal \(\mathfrak{a}\) such that \(E_i = \mathfrak{a} \star E_j\) for some \(i \neq j\). Borrowed from SeaSign, where it reduces tightly to GAIP once the class group structure is known. The variant with quadratic twists reduces to MT-GAIP.
