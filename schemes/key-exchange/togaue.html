TOGA-UE

Triple Orbital Group Action Updatable Encryption

Published

July 17, 2026

Modified

July 17, 2026

1 Overview

Updatable Encryption (UE) allows untrusted servers to update ciphertexts via tokens without exposing secret keys, ensuring forward and post-compromise security for outsourced storage. Crucially, UE differs significantly from UPKE: while UE fundamentally requires ciphertext updatability, UPKE generally does not. Historically, building post-quantum UE from group actions required Mappable Effective Group Actions (MEGA). In the isogeny setting, this is practically infeasible due to the notorious difficulty of hashing into supersingular elliptic curves. The TOGA-UE (Triple Orbital Group Action Updatable Encryption) scheme circumvents this limitation by drawing inspiration from the SiGamal encryption scheme [LeRo24]. Instead of attempting to map messages directly to an isogeny graph vertex (a curve), TOGA-UE maps messages as scalars to specific points on an elliptic curve via scalar multiplication. The underlying curve and the points are then transformed using the isogeny group action. This architectural shift eliminates the need to hash into supersingular curves while natively supporting an unbounded number of ciphertext updates. Consequently, TOGA-UE instantiated from CSIDH stands as the first post-quantum UE scheme that is not based on lattices and places no limits on key rotations.

2 Scheme Design

TOGA-UE is built upon an abstract algebraic framework known as an Effective Triple Orbital Group Action (ETOGA). To instantiate this from CSIDH, the scheme defines specific group actions operating over supersingular curves enriched with torsion point information.

2.1 System Setup

This algorithm takes the security parameter \(\lambda\) as input (which dictates the sizes of the underlying cryptographic structures) and establishes the public parameters and mathematical framework for the CSIDH instantiation.

  • Define the Field and Curve: Based on \(\lambda\), choose a large prime \(p \equiv 3 \pmod 4\) and define the base supersingular elliptic curve \(E_0: y^2 = x^3 + x\) over \(\mathbb{F}_p\).
  • Establish the Order and Torsion: Let \(\mathfrak{O} = \mathbb{Z}[\sqrt{-p}]\) be the quadratic order corresponding to the Frobenius endomorphism ring. Choose a smooth integer \(N\) (sized according to \(\lambda\)), split in \(\mathfrak{O}\) and coprime to the ideal factor base.
  • Define the State Space (\(S\)): Let \(S\) be the set of elements \((E, \iota, P)\), where \(E\) is a supersingular curve, \(\iota\) is an \(\mathfrak{O}\)-orientation, and \(P \in E[N]\) is a point of order \(N\). Fix a public origin state \(s_0 \in S\) using \(E_0\), its canonical orientation, and a deterministic base point \(P_0 \in E_0[N]\).
  • Define the Main Group Action (\(*_A\)) and Sample Space (\(A'\)): Let \(A\) be a subgroup of fractional \(\mathfrak{O}\)-ideals generated by small prime ideals \(\mathfrak{l}_1, \dots, \mathfrak{l}_n\). Define a finite subset \(A' \subset A\) bounded by a small exponent maximum \(m\) (i.e., ideals with exponents \(\in [-m, m]\)) to allow efficient, near-uniform sampling. For an ideal \(\mathfrak{a} \in A\), define its action as evaluating an isogeny: \(\mathfrak{a} *_A (E, \iota, P) = (E_{\mathfrak{a}}, \iota_{\mathfrak{a}}, \varphi_{\mathfrak{a}}^E(P))\).
  • Define the Orbital Group Action (\(*_H\)): Let \(H = (\mathbb{Z}/N\mathbb{Z})^\times\). Define the action of \(h \in H\) as scalar multiplication on the order-\(N\) point: \(h *_H (E, \iota, P) = (E, \iota, [h]P)\).
  • Establish Helper Functions:
    • Define \(\sim_A\) as the congruence relation where ideals are equivalent if they share the same ideal class.
    • Define \(\text{Reduce}_A\) to output a short, canonical representative of an ideal’s equivalence class.
    • Define \(\text{Reduce}_S\) to output a canonical representative for an equivalence class in \(S\) under the orbital action.
    • Define \(\text{Invert}_H\) as an efficient algorithm that computes the discrete logarithm between two points in \(E[N]\) to invert the group action \(*_H\).
    • Define \(\psi\) as an efficiently invertible map from the message space \(\mathcal{M}\) to \(H\).
    • Define \(h(\cdot, \cdot)\) as a function computing a structural modifier in \(H\) to correct discrepancies during ideal reduction.
  • Output: The public parameters \(pp = (A, A', H, S, s_0, *_A, \sim_A, *_H, \psi, \text{Reduce}_A, \text{Reduce}_S, \text{Invert}_H)\).

2.2 Key Generation

Generates an epoch encryption key \(k_e\) using the public parameters \(pp\).

  • Sample a bounded ideal vector \(a' \leftarrow A'\) and a scalar \(h \leftarrow H\).
  • Return \(k_e = (\text{Reduce}_A(a'), h) \in A \times H\).

2.3 Encryption

Encrypts a message \(M \in \mathcal{M}\) under epoch key \(k_e = (a_e, h_e)\).

  • Sample a random, bounded ideal \(r' \leftarrow A'\).
  • Compute reduced ideal \(r = \text{Reduce}_A(r')\).
  • Calculate the base state \(s = \text{Reduce}_S(r *_A s_0)\).
  • Return ciphertext \(C_e = (\psi(M)h_e) *_H (a_e *_A s)\).

2.4 Token Generation

Generates the update token \(\Delta_{e+1}\) used to transition ciphertexts from epoch \(e\) to \(e+1\) given keys \(k_e\) and \(k_{e+1}\).

  • Parse \(k_e = (a_e, h_e)\) and \(k_{e+1} = (a_{e+1}, h_{e+1})\).
  • Compute the ideal transition \(c_e = \text{Reduce}_A(a_e^{-1}a_{e+1})\).
  • Compute the structural modifier \(h' = h(a_e^{-1}a_{e+1}, c_e^{-1})\).
  • Return update token \(\Delta_{e+1} = (c_e, h' h_{e+1} h_e^{-1})\).

2.5 Ciphertext Update

Deterministically updates a ciphertext \(C_e\) from epoch \(e\) to \(e+1\) using the server-side token \(\Delta_{e+1}\).

  • Parse \(\Delta_{e+1} = (a, h)\).
  • Return updated ciphertext \(C_{e+1} = h *_H (a *_A C_e)\).

2.6 Decryption

Decrypts ciphertext \(C_e\) using epoch key \(k_e = (a_e, h_e)\).

  • Compute the inverse ideal \(b_e = \text{Reduce}_A(a_e^{-1})\) and modifier \(h' = h(a_e, b_e)\).
  • Undo the key’s actions: \(s' = (h_e h')^{-1} *_H (b_e *_A C_e)\).
  • Recover the canonical representative \(s = \text{Reduce}_S(s')\).
  • Extract the message by solving the discrete logarithm in the smooth-order group \(E[N]\): \(M' = \psi^{-1}(\text{Invert}_H(s', s))\).
  • Return \(M'\).

3 Security Assumptions

The detIND-UE-CPA (Deterministic Updates Indistinguishability - Updatable Encryption - Chosen Plaintext Attack) confidentiality of the TOGA-UE scheme directly relies on specific computational hardness properties embedded within the group action. Notably, TOGA-UE is a promising approach because it avoids reliance on the ideal cipher model. However, its security relies on the weak pseudorandomness of the entire TOGA structure. The core security assumptions and their nuances are detailed below:

  • Extended Weak Pseudorandomness (P-CSSDDH Connection): The core problem assumed to be computationally hard is distinguishing tuples of the form \((s_i, \mathfrak{a} *_A s_i)\) from tuples of the form \((s_i, t_i)\), where \(\mathfrak{a} \leftarrow \mathcal{D}_A\) is a secret ideal and \(s_i, t_i \leftarrow \mathcal{D}_S\) are random elements from the state space \(S\). This instantiation based on CSIDH closely aligns with the P-CSSDDH assumption.
  • Irreducibility to Standard CSIDH: Standard isogeny-based group actions assume the weak pseudorandomness of the induced class group action (\(*_G\)) operating purely on oriented curves. Unfortunately, the P-CSSDDH assumption does not reduce to the standard weak pseudorandomness of CSIDH because additional torsion point information is revealed in the extended state space \(S\).
  • Resilience and Uncertainty: The revealed torsion point information makes the exact hardness of P-CSSDDH less well understood compared to standard CSIDH. However, this revealed information is not sufficient to apply the catastrophic torsion-point attacks that broke SIDH. The degree of the secret isogeny remains unknown and uniform over a large sample, which invalidates standard Weil pairing or genus-theory reduction attacks.
